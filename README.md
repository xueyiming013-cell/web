# 팬텀 블레이드 제로 (Phantom Blade Zero · 影之刃零)
## 한국 교수님 소개 및 학술 보고용 인터랙티브 웹페이지 가이드

본 프로젝트는 한국 대학교의 교수님(게임학, 문화콘텐츠학, 미디어영상학, 컴퓨터공학, 동양문화연구 등)께 중국의 차세대 AAA 액션 RPG 기대작 **《팬텀 블레이드 제로 (Phantom Blade Zero / 影之刃零)》**를 학술적·산업적 깊이를 갖추어 소개하기 위해 제작된 고급 웹 프레젠테이션 시스템입니다.

---

### 📂 프로젝트 구성 파일
```
e:\work\
├── index.html          # 메인 웹페이지 (반응형, 한국어/영어/중국어 다국어 지원, 슬라이드 발표 모드)
├── style.css           # '쿵푸펑크' 콘셉트의 다크 수묵 & 스팀펑크 비주얼 스타일시트
├── script.js           # 다국어 번역 엔진, 앰비언트 사운드/캔버스, 무기 쇼케이스, 슬라이드 컨트롤러
├── assets\             # 고해상도 벡터 그래픽 (보스전, 스팀펑크 병기, 예일대 건축 레벨)
│   ├── screen1.svg     # 폭우 속의 사자탈 수령 진검승부
│   ├── screen2.svg     # 호효 사자포와 스팀펑크 기계 의수
│   └── screen3.svg     # 예일대 건축학 디렉터의 동양 고건축 축선
└── README.md           # 본 안내서 및 한국어 발표 대본 (스크립트)
```

### 🚀 사용 및 실행 방법

1. **로컬 브라우저에서 바로 열기**:
   - `e:\work\index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등 최신 웹 브라우저에서 바로 열 수 있습니다. (외부 서버 설치 불필요)
2. **다국어 즉시 전환**:
   - 상단 네비게이션 우측의 `한국어` / `EN` / `中文` 버튼을 클릭하면 모든 섹션과 설명이 즉시 실시간 전환됩니다.
3. **교수 면담용 [발표 모드 (Slide Mode)]**:
   - 우측 상단의 `발표 모드` 버튼을 누르면 학술 세미나/면담에 최적화된 5장의 대형 슬라이드 뷰가 활성화됩니다.
   - 키보드 좌우 방향키(`←`, `→`), 스페이스바(`Space`), `ESC` 키로 자유롭게 넘기며 설명할 수 있습니다.
4. **동양적 앰비언트 사운드 체험**:
   - 상단 볼륨 아이콘을 클릭하면 Web Audio API로 실시간 합성되는 수묵풍 저음 드론과 대나무 풍경(Wind chime) 소리가 재생되어 몰입감을 높여줍니다.

### 🎙️ 한국 교수님 면담/발표 시 추천 대본 (Speaking Script)

교수님께 정중하면서도 학술적 통찰력을 전할 수 있는 정중한 한국어 존댓말(하십시오체/해요체) 스크립트입니다:

#### 1. 도입 및 연구 배경 설명 (Opening)
> "교수님, 최근 글로벌 비디오게임 시장에서 가장 큰 화두는 동아시아 개발사들의 콘솔 AAA 시장 진출입니다. 한국에서는 《P의 거짓(Lies of P)》과 《스텔라 블레이드(Stellar Blade)》가 세계적인 성공을 거두었고, 중국에서는 《검은 신화: 오공》이 기록적인 흥행을 이뤄냈습니다.  
> 
> 오늘 제가 교수님께 소개해 드리고자 하는 작품은, 이 동아시아 차세대 액션 게임 계보의 정점에 서 있는 차기 기대작 **《팬텀 블레이드 제로(Phantom Blade Zero)》**입니다."

#### 2. 작품의 4대 핵심 가치 브리핑 (Core Pillars)
> "이 작품은 단순한 상업용 게임을 넘어 다음과 같은 학술적·미학적 독창성을 지니고 있습니다.  
> 
> 첫째, **'쿵푸펑크(Kungfupunk)'라는 새로운 장르 미학**입니다. 중국 전통의 무협(Wuxia)에 스팀펑크 기계 장치와 오컬트 괴기, 디스토피아적 신체 개조를 융합했습니다.  
> 
> 둘째, **홍콩 무술 영화 문법의 디지털화**입니다. 영화 《바람의 검심》과 견자단 무술팀의 거장인 **켄지 타니가키(谷垣健治)** 무술감독이 실사 모션캡처를 총괄하여, 소울라이크의 느린 템포를 탈피한 60프레임 초고속 '합(合)의 공방'을 구현했습니다.  
> 
> 셋째, **건축학적 공간 설계**입니다. 디렉터 양기량(Soulframe Liang)은 칭화대와 예일대 건축석사 출신으로, 당·송 시대의 전통 목구조와 다층 수직 구조를 게임 레벨 디자인에 유기적으로 해체·재구성했습니다.  
> 
> 넷째, **'66일의 유예'라는 실존주의적 시간관**입니다. 무한 부활하는 기존 소울류와 달리, 주인공의 심장이 66일 뒤 멈춘다는 시한부 설정을 통해 동양적 '제행무상(諸行無常)'과 실존적 결단을 서사화했습니다."

#### 3. 한·중 콘솔 대작 비교 및 담론 제언 (Academic Discussion)
> "웹페이지 중간의 비교표를 보시면, 한국의 《P의 거짓》이 서구 벨에포크 고전을 완벽하게 체화하고 《스텔라 블레이드》가 감각적인 SF를 다루었다면, 《팬텀 블레이드 제로》는 동양의 전통 문화를 글로벌 서브컬처와 교잡하여 '탈지역화(De-localization)'하는 전략을 취하고 있습니다.  
> 
> 향후 세미나나 연구에서 동아시아 게임 생태계가 모바일 가챠 모델에서 싱글플레이어 패키지로 체질을 개선하는 과정, 그리고 전통 문화의 현대적 디지털 번역 방식에 대해 교수님의 고견을 여쭙고 싶습니다."

### 💡 주요 학술 키워드 요약 (Academic Glossary)
* **Kungfupunk (쿵푸펑크)**: 동양 무협 + 스팀펑크 + 다크 판타지가 융합된 하이브리드 미학.
* **合 (합의 공방)**: 공격과 방어가 쉼 없이 주고받는 홍콩 정통 무술 영화의 교전 리듬.
* **De-localization (탈지역화)**: 특정 지역의 고유 서사(무협)가 글로벌 보편 기호와 결합해 국경을 넘는 현상.
* **66-Day Temporality (66일의 시간성)**: 루돌로지(Ludology)적 긴장감을 부여하는 실존적 시한부 내러티브.
